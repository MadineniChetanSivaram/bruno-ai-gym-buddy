# 🐻 Bruno — AI Gym Buddy

**Autonomous, Mascot-Driven Strength Programming & Biomechanical Engine in React Native**

---

## 📖 Overview
Bruno is an intelligent strength coaching mobile application built with React Native and Expo 52. Guided by **Bruno** — a wise, chalked-up heavyweight bear carrying an old-school lifting notebook — the app provides zero-fluff, periodized lifting programs tailored to the lifter's actual gym hardware and injury history.

---

## ⚡ Core Features
1. **Mascot Persona (Bruno)**: Stateful coaching companion with pre-session chalk briefings, post-workout encouragement, and weekly verdict reviews.
2. **Multi-Gym Hardware Switcher**: Dynamically adapts routines across Commercial Gyms (50kg dumbbells, barbells, full cables), Apartment Gyms (24kg max dumbbells, cables, pull-up bar), and Home Studios (20kg dumbbells).
3. **1-Tap "Machine Busy" Swap**: Biomechanically matches 3 immediate replacements sharing the same primary muscle and movement pattern (e.g., horizontal push) without leaving your workout.
4. **Joint Injury Protection**: Automatically removes axial spinal loads or impinging angles for lower back, shoulder, knee, wrist, or elbow pain.
5. **30-Second Frictionless Log**: 1-click "Hit Targets" button, 1–10 RPE effort slider, and joint soreness tracking.
6. **Progressive Overload Engine**: +2.5 kg on upper compounds and +5 kg on lower compounds upon target completion with automated 6-week deloading.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Expo CLI (`npx expo`)
- Expo Go on iOS or Android

### Installation & Run
```bash
# Navigate to the project
cd bruno-ai-gym-buddy

# Install dependencies (if not using shared modules)
npm install

# Start the Expo development server
npx expo start

# Run directly on web
npx expo start --web
```
